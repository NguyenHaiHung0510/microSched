## 2024-11-20 - Ensure Explicit ARIA Labels for Icon-only UI Components
**Learning:** Found an icon-only button inside the Dialog component that used a screen-reader-only `<span>` inside the button for accessibility, instead of a direct `aria-label` attribute on the button element itself. While `<span className="sr-only">` works, an explicit `aria-label` on the button component is cleaner, explicitly standard, and prevents the screen reader from double reading if both the label and the inner span were somehow presented differently.
**Action:** When inspecting or adding icon-only UI components, ensure that an explicit `aria-label` is applied directly to the interactive component rather than relying exclusively on inner invisible text nodes, making the intention absolutely clear in the JSX attributes.
