No production mark is derived from these boards in Task 058C. The temporary
functional icon in the app is explicitly not a Mimi identity asset. The earlier
code-native interpretation was rejected by the Owner and removed rather than
being allowed to become an accidental standard.

Before product use, a separate identity package must provide canonical source
assets and exports, geometry/silhouette and clear-space rules, palette/tokens,
size variants, semantic motion states with a reduced-motion fallback, usage and
anti-invention rules, plus a manifest with hashes. Once approved, the project
AGENTS/UI brief should link to that package so executors consume named assets
instead of interpreting these raster references independently.
